# IQ200 Seven-Layer Completion

This release adds seven concrete layers on top of the real-provider architecture:

1. **Stale/mock-reference cleanup** — the runtime provider status is explicit; no fake provider is used as a production fallback.
2. **Autonomous pattern discovery** — mines feature conjunctions from supplied labeled observations and reports support/lift. Promotion remains gated.
3. **Persistent semantic market memory** — append-only decision/outcome memory with deterministic feature similarity and outcome digest.
4. **Independent/calibrated council** — specialist votes plus Bull, Bear, Adversarial Challenger and Chief Judge; RiskEngine remains authoritative.
5. **Advanced order-flow sequence analysis** — time-series imbalance, spread, rapid depth changes, liquidity-vacuum and spoofing-like anomaly flags. It does not claim to prove spoofing.
6. **AI Command Center** — live health, council, twin, memory, strategy, execution and audit sections in the web cockpit.
7. **Real certification evidence gate** — certification plan explicitly distinguishes executable code from external evidence. No synthetic sandbox trades or fabricated historical performance are counted as PASS.
