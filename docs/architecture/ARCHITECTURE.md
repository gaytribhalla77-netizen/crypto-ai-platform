# Architecture

User -> Web/Telegram/Voice -> Command API -> AI Chief Operator -> Risk Manager -> Execution Engine -> Binance

Parallel intelligence:
- Market data
- Technical analysis
- News intelligence
- Sentiment
- Market regime
- Portfolio
- Opportunity scanner

Open positions are continuously monitored by market/news/risk workers.

The Risk Manager has veto authority over trade execution.

All important decisions and exchange events must be auditable.
